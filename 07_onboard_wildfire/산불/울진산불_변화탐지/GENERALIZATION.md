## 판정 기준 (3그룹)
1. **정확도** — 양성 IoU/F1, precision/recall (mIoU는 배경이 부풀리니 지양)
2. **일반화** — 교차지역 held-out (in-domain 정확도가 아니라 이게 "아무 지역이나"의 진짜 지표)
3. **온보드** — 지연·메모리·에너지·모델크기 (미측정)

## 실험과 결과

### A. 다지역 dNBR-유사라벨 학습 → 울진 홀드아웃
지중해(그리스)·미국·칠레 dNBR-Otsu 유사라벨로 학습, 울진 미학습 테스트.
- 울진(유사라벨): F1 **0.887** / IoU 0.796 — CaBuAr 전이 9.3% 대비 폭등처럼 보임.
- **하지만 CaBuAr 실측 재검증**: F1 **0.373** ≈ dNBR-echo **0.386**.
- → **모델이 dNBR 채널을 재현할 뿐**, dNBR을 넘지 못함(유사라벨=입력채널 순환). 0.887은 순환 착시.

### B. 다지역 실측라벨(MTBS 7생태권) → CaBuAr 홀드아웃
MTBS 기관 실측 경계(OR·AZ·CO·NM·ID·WA·MT 대형 산불 7개, 474타일)를 래스터화해 실측 라벨 학습.
- VAL(MTBS): F1 **0.964** — in-domain 우수.
- **TEST(CaBuAr 실측): F1 0.268 / precision 0.156** — dNBR-echo(0.386)보다도 낮음(과예측).
- 원인: **라벨 정의 불일치** — MTBS=화재경계 전체(타일당 불탄 50%) vs CaBuAr=실제 불탄픽셀(5.7%). 분포가 달라 MTBS 모델이 "넓게 다 태웠다"로 과예측. + 도메인 갭.

### 종합
| 접근 | in-domain | 교차지역 실측(CaBuAr) |
|---|---|---|
| dNBR-echo (baseline) | — | 0.386 |
| 다지역 dNBR-유사라벨 | 높음(순환) | 0.373 |
| 다지역 실측(MTBS) | 0.964 | **0.268** |
| CaBuAr-native(실측) | 0.648 | (교차 안 됨) |

## 결론
- **"다지역 학습"도, "다지역 실측라벨"도 교차지역 일반화를 못 뚫음.**
- 진짜 병목: ① 실측 라벨 희소(사실상 CaBuAr=캘리포니아뿐), ② **데이터셋 간 라벨 정의가 달라 섞으면 과예측**(MTBS 경계 vs CaBuAr 픽셀), ③ 도메인 갭.
- 실용 해법: **dNBR 기반이면 지역 불변 매핑은 되나(USGS 표준), dNBR을 넘으려면 "타겟 지역의 일관된 실측 라벨"이 필요** — 이게 없으면 온보드 범용 탐지는 지역별 튜닝이 현실적.

## 해결 (2026-08-15) — 병목은 "라벨 정의 일관성"이었다

Sen1Floods11(홍수)이 10+개국 단일 프로토콜 hand-label로 교차지역 일반화(볼리비아 0.90)에 성공한 것에서 착안 →
산불 실패의 원인은 **라벨 정의 불일치**임을 규명하고 통일했다.

### #1 라벨 정의 통일 (경계전체 → 픽셀단위)
MTBS 라벨을 `perimeter ∩ (dNBR채널>0.575)` 로 재정의 → 타일당 불탄 50%→**5.6%**(CaBuAr 5.7%와 정합).
- **CaBuAr 실측 F1 0.268 → 0.547**, precision 0.156→0.412 (과예측 해결).
- **dNBR-echo(0.386)를 처음으로 넘음.** 미국 7생태권만 학습→캘리포니아 = 순수 교차지역 일반화.
- `src/mtbs_train_v2.py`, `runs/mtbs_cd/mtbs_v2_results.json`.

### #3 하모나이제이션 (CaBuAr 실측 + MTBS 일관화 통합)
CaBuAr-train(780, CA 실측) + MTBS 일관화(435, US 7생태권) = 1,215타일 통합 학습 → CaBuAr-test.
- **F1 0.664 > 단일지역 CaBuAr-native 0.648** — 일관 다지역 실측이 단일지역을 능가.
- 동일 조건(둘 다 CaBuAr-train 사용)에서 MTBS 다지역이 순기여.
- `src/mtbs_train_v3.py`, `runs/mtbs_cd/mtbs_v3_results.json`.

## 최종 결론 (positive)
- **병목은 모델·데이터양이 아니라 "라벨 정의 일관성"이었다.** 정의를 통일하니 다지역→교차지역 일반화가 살아났고(0.547, echo 돌파), 일관 다지역을 합치니 단일지역을 능가(0.664).
- **온보드 범용 산불탐지의 해법 = Sen1Floods11식 "일관 다지역 실측라벨"**. 실측 소스가 여럿이면(MTBS·CaBuAr) **단일 픽셀 정의로 하모나이즈**해야 섞인다.

### 결정적 발견
- **같은 화재체제(여름·건기 산불 = 양의 dNBR) 안에서는 어느 생물군계로도 일반화됨** — 붕괴 없음, dNBR 이상. dNBR 초과 값어치는 도메인 거리에 반비례: 지중해 +0.16 → 한대림 +0.065 → 유칼립투스 +0.008(사실상 0).
- **다른 화재체제로는 붕괴 (한국 −0.609).** 한국 봄산불은 **개엽기(4-5월)에 발생** → pre(개엽 전)→post(개엽 후) 계절 초록화가 소실신호를 반전. 대형산불(5502ha)조차 산불 5일후 영상에서 **불탄 dNBR = raw −0.21~−0.55 (음수)**. dNBR 피처 자체가 소실정보를 안 담음 → dNBR-echo·US모델 **둘 다 실패**.
- 즉 벽은 "생물군계 거리"가 아니라 **화재체제(계절·페놀로지) 도메인 이동**. 한국은 **native 학습만이 답**(uljin 프로젝트 native F1 0.772로 이미 입증).

### 데이터 벽 (미검증)
- **열대·사바나**: 20m급 실측 라벨 희소(MODIS 500m는 무의미). (동아시아 열대는 별개 생물군계 — 한국 데이터로 커버 불가)

### 최종 결론
**온보드 범용 산불탐지:**
1. **여름·건기 산불체제(양의 dNBR) 내부** → "어디서나 dNBR 베이스라인 보장", 그 이상은 유사/in-domain 실측라벨 필요. (지중해·한대림·유칼립투스 확인)
2. **봄산불 등 다른 화재체제** → dNBR 피처 자체가 반전/소실 → **US 모델 드롭인 불가, native 학습 필수** (한국 붕괴 −0.609 vs uljin native 0.772).

→ 벽은 라벨 수량이 아니라 **① 화재체제/페놀로지 도메인 이동 + ② 일관 다지역 실측라벨 정의**. Sen1Floods11식 접근이 정답인 이유가 다생물군계+다화재체제로 재확인됨.
