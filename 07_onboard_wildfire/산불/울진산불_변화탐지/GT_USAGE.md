# 자(尺)별 사용 범위 — 어떤 GT 로 무엇을 말할 수 있는가

이 프로젝트에서 판정이 뒤집힌 사고는 대부분 모델이 아니라 **자를 잘못 골라서** 났다.
그래서 자마다 **할 수 있는 판단과 못 하는 판단**을 여기 고정한다. 성능을 인용할 때는
숫자와 함께 **어느 자로 쟀는지**를 반드시 같이 적는다.

| 자 | 쓸 수 있는 판단 | **쓰면 안 되는 판단** |
|---|---|---|
| **안동 NIFoS 0.3m** (KCBI 학습 자동분류) | 그 사건의 면적·분류 성능, 임계값 판정 | 전국 일반화 주장 (사건 1건이다) |
| **RapidEye 5m 부분 라벨** (강릉·고성·양양·인제) | 라벨된 구역 **안**에서의 검출률(리콜), 심각도 등급 | 전체 사건의 정밀도·총면적·해상도 우열 — **라벨 밖을 비피해로 간주하지 말 것** |
| **강릉 심각도 GT** | 안동과 같은 소각강도 영역에서의 전이 성능 | 다른 소각강도 영역까지의 보편성 |
| **울진 GT** (원본 20m·S2 기반) | 개발 중 일관성 확인·회귀 검사 | 독립 정확도, 해상도 우열 — **순환이다** |
| **산림청 경계 폴리곤** | 위치·공간 범위 참고, 라벨 오류 분석, **회귀 감지** | 모델 **순위**, 성능의 하한/상한 주장 |
| **CIR-GT** (S2 dNBR/dNDVI 절단) | 학습·준순환 보조 지표 | 임계값·해상도 판정 |

## 표현을 정확히 — "산림청 폴리곤은 하한 전용"은 부정확했다

과대(경계) 라벨이라는 사실만으로 그 자로 잰 점수가 **실제 성능의 하한이 되지는 않는다.**
편향의 방향이 모델 성향에 달려 있기 때문이다 — 넓게 칠하는 모델은 이 자에서 과대평가되고,
좁게 칠하는 모델은 과소평가된다. 정확한 용법은 이렇다:

- **된다**: 같은 모델을 시간에 따라 재서 **점수가 떨어지면 회귀 신호**로 쓴다.
- **안 된다**: 서로 다른 모델의 **순위**를 매기는 것. 실제로 2026-09-09 하루에만 두 번
  틀린 1위를 매겼다(post-only, SWIR 12ch — 둘 다 안동에서 뒤집혔다).
- **안 된다**: "적어도 이만큼은 한다"는 하한 주장.

## 심각도 GT 는 두 조건을 먼저 통과해야 한다

`src/sev_transfer.py:gate` — 채점 **전에**, 모델 출력 없이 판정한다.

1. **순서**: 등급별 dNBR 중앙값이 심 > 중 > 경
2. **눈금**: 기준 사이트(안동) 대비 배율 0.7~1.4

통과 안동·강릉 / 탈락 고성·양양(순서 역전)·인제(눈금 0.51배). 4사이트 전이 결과를 4/4 맞췄다.

**인제는 시험 자료로 남긴다.** "심 dNBR 이 0.51배였다"를 보고 일괄 보정하면 시험 자료에
맞춘 보정이 된다. 보정에 쓰려면 인제를 **개발 자료로 전환**하고 새 독립 시험지를 확보할 것.

## 면적 검증을 늘리는 길 — 전수 경계 대신 확률표본

완전한 화재 경계를 새로 확보하지 못해도 면적 검증은 설계할 수 있다.
피해 예측지역 · 비피해 예측지역 · 경계지역에서 **확률표본**을 뽑아 독립 영상이나 현장
자료로 판독하고, **추출확률을 반영해** 면적과 오차를 추정한다. 전체 경계를 그리는 것보다
판독량이 훨씬 적다. 부분 라벨의 바깥을 비피해로 간주하는 실수를 구조적으로 피할 수 있다.
(미착수 — 독립 면적 자를 늘리는 현재 유일한 현실적 경로다.)
