# 산불 확산·대피 예측 파이프라인 — 설계 & 로드맵

작성 2026-09-05. 대상: "불이 나면 위성으로 확산과 대피로를 예측해 정보를 송출"하는 운영 파이프라인 설계.

## 핵심 전제 (정직한 제약)

**위성 광학(Sentinel-2)으로는 확산을 실시간으로 볼 수 없다.** 주기 5일 + 구름.
우리 메모리에 확정된 벽: active-fire NHI·FIRMS-RF 실시간 화염탐지 = NEGATIVE, 정밀 실시간엔 열적외(GK-2A) 필요.

→ "확산 예측"의 정체:
> **위성 열점(발화·화선 위치) + 지형·연료·기상 → 물리 확산모델이 예측, 매 위성패스 열점으로 보정(assimilation).**
> 확산은 *모델*이 예측하고 위성은 *씨앗(발화점)*과 *정답지(화선 검증)*를 준다.

## 두 개의 시계 (트랙 분리)

| | during-fire (실시간, 분~시간) | after-fire (사후, 일 단위) — 현 강점 |
|---|---|---|
| 목적 | 확산 예측 + 대피 정보 송출 | 피해면적·피해평가 |
| 위성 | 열적외 열점 (GK-2A 10분·2km / VIIRS·MODIS FIRMS 375m) | S2 광학 seg-CD 소각범위 |
| 코어 | **물리 확산모델** (미구현=공백) | 우리 cd_unet/CIR-GT (봄 cross-fire **best-thr 0.847 · 배포 thr 0.25 에서 0.782**) |
| 산출 | 시간별 도달시각 T_fire(x,t) → 도주로 | 소각 폴리곤·면적 → 피해평가 |

우리 대피 모듈은 during-fire 트랙이나, 현재 도달시각을 "이미 지나간 FIRMS 관측"으로 채움(사후 재구성). 이를 **예측 필드로 교체**하는 것이 미싱 링크.

## 실시간 트랙 데이터 흐름

```
[발화]
 ① 열점 탐지  ── GK-2A 열적외(조기경보 2km) + FIRMS VIIRS/MODIS(375m 위치)
 ② 프리컴퓨트(오프라인 상시): DEM→경사/향 · 연료지도=EGIS 토지피복 · 도로망 OSM · 대피소/읍면 POI
      + 실시간 기상(KMA 바람·습도·기온)
 ③ 물리 확산모델 ── 셀룰러오토마타(경사+바람+연료) or Rothermel/FARSITE류
      → 시간별 화재 도달시각 필드 T_fire(x,t)   ↑ 매 패스 FIRMS 열점으로 검증·보정
 ④ 대피 라우팅 ── (evacuation 모듈: margin = T_fire − T_escape)
      · 살아남을 대피소 예측(불길 앞 목적지 제외) · 화재-회피 시간의존 라우팅
 ⑤ 송출 ── 읍면별/위험건물별 골든타임 + 도주로 + 지정 대피소
```

## 로드맵

- **V0 — 완료**: FIRMS 관측 시퀀스 → 관측 도달시각 → 대피 margin/도주로 (사후 재구성).
  - 구현: `src/uljin_evacuation.py` + isolation/exposure/time_dependent. 실제 안전목적지(OSM 대피소 203·읍시 19) 기반.
  - 검증결과: 위험권 482동 중 갇힘 2동(발화점 인근), 마진 중앙 +12.3h, 탈출거리 중앙 1.8km.
  - ★부수 발견: 조밀 도로망에서 '연결성 고립'≈0(위상차단·우회거리폭발 둘 다 0) → 위험은 연결성이 아니라 '도착 vs 탈출' 시간경쟁으로 재정식화.
- **V1 — 물리 확산 코어 ✅완료(2026-09-06)**: `src/uljin_firespread.py`. 최소도달시간(MTT/Finney 2002)
  격자 CA — 방향별 ROS = R0·연료(EGIS)·exp(K_S·경사성분)·exp(W_STR·풍향정렬), 씨앗=첫 FIRMS
  오버패스(79점), 다중소스 Dijkstra로 도달시각 필드 T_fire(x). 입력: Copernicus DEM 30m(경사)
  + EGIS 토지피복(연료 3분류) + FIRMS(씨앗·검증). 격자 100m, 232×216.
  - **검증(울진 2022):** ① 도달순위 Spearman **ρ=0.564**(p<1e-89, n=1059; 풍향은 도달순위와
    독립인 기하량='씨앗→최원거리' 10°로 고정 → 순환 아님). ② 예측 도달 FIRMS 셀 99%. ③ 최종
    소각범위 vs seg-CD 흉터 **IoU 0.437 / F1 0.608**(recall 0.974, precision 0.442=미억제 과확산).
    시계열 recall 45%→99% 단조증가.
  - ★V1 핵심 발견: **최종 소각범위는 풍향에 강건**(전 방향 IoU 0.43–0.54)하나 **도달순위는 가정
    풍향에 극히 민감**(ρ −0.18~+0.81). FIRMS는 오버패스 이산(~12h·24회)+첫패스가 이미 큰 전선이라
    **독립적 풍향신호를 담지 못함** → 시간 순서의 정밀검증엔 실측 기상(KMA)·고빈도 열적외(GK-2A)가
    필수 = 정확히 **V2의 근거**. 한계: R0는 관측 중앙시각에 스칼라 정규화(공간패턴 불변), 연료 3분류
    (임상차 미반영), 상수바람, 미억제(진화활동·방화선 미모델).
- **V2 — 실측 시변기상 결합 ✅완료(2026-09-06)**: `src/uljin_firespread_v2.py`. Open-Meteo ERA5(키불필요)
  발화지점 시간별 풍향·풍속·습도 → MTT Dijkstra에서 셀 도달시각별 바람 적용(FIFO 시간의존). ROS에
  풍속(exp(KW·U·cosΔ))·습도(exp(-KM·RH))까지 실측 반영. 울진: 발화 04시 서풍(→동진)→오후 남서풍
  (→북동진) 6m/s·RH15~20% 회전 포착.
  - **★타임존 정정(2026-09-06):** FIRMS acq는 UTC인데 초기 ERA5를 KST로 받아 바람이 ~9h 어긋났었음
    (발화 실제는 오후지만 새벽 바람 적용). GMT로 재취득해 정정 → 발화 바람 toward 48°(NE, 실제 삼척방향
    확산과 부합)·5.8m/s·RH19%(양간지풍).
  - **검증(정정 후, V2 실측시변풍 vs V1 상수기하풍):** 도달순위 ρ **0.534 vs 0.538(≈동률)**, 범위 IoU
    0.427 vs 0.421. → **올바로 시간정렬한 실측 바람은 좋은 상수 추정 대비 울진 FIRMS 검증에서 이득
    없음**(이전에 보고한 +8pp는 타임존 버그가 부풀린 값 — 정정). 이유: 발화 바람(NE)이 이미 화재 전체
    확산축과 일치 → 이후 회전은 FIRMS(오버패스 이산)로는 분해 불가. V1의 발견(FIRMS는 미세 바람효과를
    분해 못함)을 오히려 재확인. V2의 가치는 '단일각 미상인 실전에선 실측 바람이 상수 추정을 대체'하는
    운영적 이점(사후 최원거리 기하를 못 쓰는 실시간). 필드 저장 runs/uljin_tfire_v2.npz.

## ★일반화 검증 완료(2026-09-06) — 제2 화재로 이식

`src/firespread_general.py` (화재 무관 모듈: burn_mask + FIRMS bbox CSV + Copernicus DEM + EGIS + ERA5 UTC).
제2 화재 = **산청 2025**(fire_142, 2,969ha, 남부 내륙산악, 2025-03 — 울진과 지역·연도·계절 완전 상이).

| 화재 | 도달순위 ρ | 범위 IoU | 범위 recall | 범위 precision | 초기 recall |
|---|---|---|---|---|---|
| 울진 2022 | 0.523 | 0.427 | 0.974 | 0.432 | 54% |
| 산청 2025(미학습) | 0.285 | 0.193 | **0.947** | 0.195 | 82% |

**★결론: 물리 CA는 미학습 화재에 이식된다(붕괴 없음).** ρ 양수 유지·범위 recall 0.95+(실제 흉터의 95%를
예측 envelope가 포함) — seg-CD가 한국 봄산불서 F1→0.0로 붕괴한 것과 대조적으로 **우아하게 저하**.
가설(물리는 학습보다 이식 유리, R0만 화재별 정규화) 확증. **약점=precision(과확산)**: 미억제 물리
envelope는 진화·방화선·연료수분 이질성을 모델 안 함 → 실제보다 많이 태움, 특히 소형·억제 화재(산청
precision 0.195 < 울진 0.432)서 심함. 함의: 이 모델은 '실제 소각'이 아니라 **위협 envelope(대피 대상
구역)** 예측기 — recall 0.95+가 그 용도엔 정확히 맞음(위협지역 놓치지 않음). 소각면적 산정은 여전히 seg-CD.

## precision 개선 시도 = NEGATIVE(2026-09-06) — 흉터-독립 지형/연료 선험으로는 불가

과확산(precision 울진0.43·산청0.20) 완화 시도. 순환 회피 위해 **흉터 비참조 물리선험만** 사용:
- **레버1 사면향-수분(소프트)**: 북사면·계곡 습→ROS↓(한국 봄산불 남사면 편중, 순수 DEM). 결과=**무효**
  (울진 IoU 0.427→0.424, 산청 0.193→0.186). 이유: R0 재정규화하면 느려진 셀도 긴 시간지평서 결국 탐
  → 최종 envelope 불변. **과확산은 '느림' 아닌 '시간지평 내 도달' 문제.**
- **레버2 소멸임계(하드배리어)**: 연소적합도(연료×향수분)<thr 셀 전파정지. 결과=**무효/악화**
  (thr↑ 시 precision 0.43→0.45 소폭↑이나 recall 0.97→0.84 붕괴, IoU 순증 없음; 산청은 thr 0.15부터
  recall 0.95→0.74 급락). 이유: 과확산이 북사면·저연료에 국한 안 되고 **공간적으로 확산** → DEM 배리어가
  진짜 소각까지 잘라냄. (진단 코드는 `SWEEP=1` env로 재현 가능, 느림.)

**★결론: precision은 흉터-독립 지형/연료 선험으로 개선 불가.** 실제 화재를 멈춘 건 **진화활동·방화선·
기상급변**(역사 화재엔 공개 안 된 운영데이터). 이 모델의 정체성 재확인=**위협 envelope 예측기(recall
0.95+)**, 소각면적 정밀추정은 seg-CD 담당. precision 향상엔 화재별 진화작전 데이터(소방 GIS)나 실시간
화선진행 동화(GK-2A)가 필요 — 이건 데이터·인프라 문제이지 모델 문제 아님.
