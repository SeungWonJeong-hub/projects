# 소량 픽셀 GT 손라벨 — 라벨 벽 정직 측정용

딥리서치(2026-08-24) 판정: 한국 봄산불 F1 벽의 정체는 **산림청 경계폴리곤 라벨 노이즈**(픽셀정밀 아님).
loss 트릭(NAL)은 flat로 negative — **진짜 픽셀 GT가 없으면 어떤 라벨레버도 측정 불가**(SAM2·NAL이 증명).
→ 홀드아웃 11타일에 소량 픽셀 GT를 손으로 만들어 "진짜 검증셋"을 확보한다.

## 왜 사람이 해야 하나 (자동 불가)
자동 제안은 전부 같은 20m 신호에서 나와 **순환**(모델이 만든 걸 모델로 검증 = 착시).
검증셋은 **사람 눈이 최종 판단**해야 가치가 있다. 그래서 이 한 단계만 수동.

## 각 타일 폴더 파일
- `post_swir.tif` — 화재 후 SWIR 위색. **소각지=빨강/주황**, 건강식생=초록. (라벨링 배경)
- `pre_swir.tif` — 화재 전 (비교용, 초록이던 곳이 후에 빨강=소각)
- `polygon_gt.tif` — 산림청 폴리곤 (참조; 이게 부정확한 라벨)
- `model_pred.tif` — 현재 모델 예측 (폴리곤과 불일치 지점=판단 필요한 곳)
- `hand_gt.tif` — ★**편집대상**. polygon 으로 초기화됨. 이걸 진짜 소각픽셀로 고친다.
- `preview.png` — pre|post / polygon(노랑)|pred(빨강) 4분할 빠른 확인

## QGIS 작업 (타일당 5-15분, 총 11타일)
1. `post_swir.tif`(배경) + `hand_gt.tif`(위) + `model_pred.tif`(참고) 열기
2. `hand_gt` 레이어 → 편집 모드. **post_swir의 붉은 소각영역에 정확히 맞춰** 칠하기:
   - 폴리곤이 놓친 붉은 소각 → **추가**(1로)
   - 폴리곤 안인데 안 탄(초록·물·구름) → **제거**(0으로)
3. 저장. (georef 더미라 픽셀공간 편집이면 됨 — 좌표 무관)
4. 다 하면(일부만 해도 됨): `python3 src/score_handgt.py`

## 결과 해석 (score_handgt.py)
- **baseline_vs_hand > baseline_vs_poly(0.677)** → 모델이 폴리곤보다 진짜 소각을 잘 맞힌 것 = **폴리곤이 천장을 눌렀던 것**(진짜 F1은 더 높음).
- **NAL_vs_hand > baseline_vs_hand** → NAL 등 라벨레버가 진짜 GT선 실제 이득(폴리곤 평가가 가렸던 것).
- **poly_vs_hand** = 폴리곤 라벨이 얼마나 노이즈였는지(라벨 벽의 실제 크기).
