# 손라벨 활성 학습 묶음 (labelset_al) - 앙상블 불일치 순 라벨 후보

만든 날 2026-09-09. 스크립트 src/al_select_tiles.py. 기록 logs/al_select.log.

## 순위가 뜻하는 것
- 9 개 모델(runs/ens2_{unet,fpn,deeplabv3plus}_s{1,2,3}) 로 ko_refl 타일 71 개를 모두 예측했다.
- 불일치(mean_std): 모델 간 확률 표준편차의 유효 화소 평균. 크면 모델들이 서로 다르게 답한 곳이 많다.
- 어긋남(mismatch): 앙상블 판정(9 모델 thr 평균 0.119) 과 산림청 폴리곤이 다른 유효 화소 비율.
- 점수(score) = 정규화(불일치) + 정규화(어긋남). 봄 타일은 1.3 배 (개엽기 반전이 문제인 계절).
- 이 점수가 높은 타일부터 사람이 라벨하면 같은 시간으로 모델과 폴리곤이 가장 많이 다투는 곳의 정답을 얻는다.
- 전체 순위는 ranking.csv, ranking.json. 선택은 상위 12, 화재당 최대 3, 기존 labelset/ 에 있는 타일은 제외.
- 홀드아웃 화재 타일은 대부분 이미 labelset/ 에 있어 제외됐고, 이번 선택 12 개는 전부 학습 화재 타일이다.
  (홀드아웃 중 아직 없는 타일은 kf_20210425_5496ha 의 나머지 4 개 정도인데 이미 labelset/ 에 들어 있다.)

## 폴더 구성 (타일마다)
- post_swir.tif  화재 후 SWIR 위색(R=B12, G=B8A, B=B04). 소각지 = 빨강, 주황. 라벨링 배경.
- pre_swir.tif   화재 전 위색. 비교용.
- polygon_gt.tif 산림청 폴리곤 (참조, 부정확한 라벨).
- model_pred.tif 앙상블 판정 (thr 0.119).
- disagree.tif   모델 간 표준편차 지도 (0~255 = std 0~0.5). 밝을수록 판단이 필요한 곳.
- valid.tif      유효 화소.
- hand_gt.tif    편집 대상. polygon 으로 초기화됨. 이것을 진짜 소각 화소로 고친다.
- preview.png    pre, post, polygon(노랑), pred(빨강), disagreement 다섯 칸.
모든 GeoTIFF 는 같은 더미 격자(256 x 256, 20 m, EPSG:32652) 라 QGIS 에서 정확히 겹친다.

## QGIS 작업 (타일당 5~15 분)
1. post_swir.tif(배경), hand_gt.tif(위), model_pred.tif 와 disagree.tif(참고) 를 연다.
2. hand_gt 층을 편집 모드로. post_swir 의 붉은 소각 영역에 정확히 맞춰 칠한다.
   - 폴리곤이 놓친 붉은 소각 -> 1 로 추가.
   - 폴리곤 안인데 안 탄 곳(초록, 물, 구름) -> 0 으로 제거.
   - disagree 가 밝은 곳을 먼저 본다.
3. 저장. 좌표는 더미라 화소 공간에서 편집하면 된다.

## 라벨 뒤 채점
- src/score_handgt.py 는 옛 AlphaEarth 모델(ko_ae, runs/ko_ae_*) 과 labelset/ 경로에 고정돼 있어 이 묶음에는 그대로 못 쓴다.
  현재 smp 앙상블에 맞는 채점기는 따로 만들어야 한다(model_pred.tif 대 hand_gt.tif, polygon_gt.tif 대 hand_gt.tif 를 valid 안에서 F1 로).
  hand_gt 가 polygon 과 같은(아직 수정 안 한) 타일은 제외한다.
