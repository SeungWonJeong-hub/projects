# 울진 산불 seg-CD — 2026-08-25 세션 결과

## 최종 성과 (미학습 홀드아웃, 고정 8화재)
| 모델 | F1 | 비고 |
|---|---|---|
| 이전 배포 (GN-UNet, 이미지입력) | 0.621 | 구 baseline |
| smp ResNet34 단일 (확장 native) | **0.665** | 웹앱 배포본 (DeepLabV3+) |

- **산림청 라벨은 행정/면적집계용 폴리곤**이라 픽셀정밀이 아님(내부 미연소 뭉갬 + 외곽 스팟 누락 ~12% under-label + 경계퍼지) → 정밀 seg로 재면 완벽 모델도 ~0.70대 상한.
- 앙상블 계절 균형 (봄0.64·여름0.70·가을0.69·겨울0.67). 전체 0.673은 봄 하드케이스(phenology)가 발목.
- ※손라벨 대비 검증은 이전(AlphaEarth) 모델 건이라 **현재 smp 모델엔 미적용** — 별도 표기 안 함.

## 이번 세션 핵심 발견
1. **해외 전이학습 종결(negative)**: 일본148+미동부112 봄산불 사전학습→한국 파인튜닝. 하모나이즈(팽창)로 zero-shot 0.002→0.243 부활했으나, 파인튜닝/조인트 전부 native(0.616~0.628)에 수렴, **못 넘음.** 병목=라벨품질+봄phenology, NOT 데이터양. (단 joint 모델은 앙상블 다양성으로 기여)
2. **native 데이터 확장(2.3배)**: MTfire.shp(2011-2021, 5084 실제폴리곤) 감사 → 빌드 26화재는 under-use. **원인=S2 L2A 아카이브공백(2015-2016)** 이라 2016-2017 화재는 pre(전년도) 부재. → **pre를 same-year(화재직전)로 fallback** 하여 2017 unlock → **26→61화재.** 개별 모델 상승(unet 0.556→0.614), 앙상블 안정성 대폭 개선.
3. **라벨 천장 규명**: 산림청은 행정/통계용 폴리곤(면적집계 목적)이라 픽셀정밀 아님 — 내부 미연소 뭉갬 + 외곽 스팟 누락(under-label) + 경계퍼지. 정밀 seg로 재면 완벽 모델도 ~0.70대 상한. 대형 상위 4화재선 앙상블이 이미 0.707 = 천장 도달.
4. **ET-02(RGB+NIR, SWIR無) 실험**: SWIR 없어도 unet 0.651 ≈ 12밴드 0.650 — 라벨천장이 둘 다 캡해 SWIR 이점이 가려짐. (9모델 확인 중)

## 파이프라인 (smp_cd.py 통합)
- Early Fusion U-Net (smp ResNet34/ImageNet, in12 = B02·B03·B04·B8A·B11·B12 × pre/post)
- recall-Tversky+BCE, 회전+flip aug, BIGNORE(경계밴드 loss무시=under-label 대응)
- 디코더 교체(unet/fpn/deeplabv3+), 앙상블(확률맵 평균), mIoU 병기
