# 초고해상도 소각영역 산출 트랙 — 조사·의사결정 정리 (2026-09-06)

기존 20m Sentinel-2 소각 변화탐지(산림청 in-domain 0.642 · 봄 cross-fire 0.782, **둘 다 배포 thr 0.25**;
best-thr 로는 0.682 / 0.847 이고 0.828 은 제로패딩 버그가 섞인 옛값이다)를
**더 높은 해상도로 확장** 가능한지 조사한 결과와 다음 스텝.

## 0. 핵심 결론 (한 줄)
병목은 **해상도가 아니라 "고해상도 + NIR"의 동시 확보**다. RGB만 늘려도 소각은 안 보인다
(0.25m RGB 육안검증 실패 기록: `NGII_LABEL_FINDINGS.md`). 진짜 native 고해상 NIR은 전부 유료.
따라서 **무료 해상도 사다리(S2 10m → PlanetScope 3m)를 먼저 소진**하고, 실익 확인 후에만 유료로 간다.

## 1. 보유 API 키 (실측)
- `NGII_APIKEY` (~/.secrets/ngii.env): 국토정보플랫폼 항공정사영상. **RGB 전용**(WMTS/WMS/WCS 전수검증). NIR GeoTIFF 경로 없음.
- `SAFETYDATA_KEY` (~/.secrets/safetydata.env): 재난안전데이터. 소각 extent 아님(예보/통계 계열 추정).

## 2. 소스별 지형 (NIR 포함 여부·비용·발사연도)

| 소스 | 해상도(NIR native) | SWIR | 비용 | 비고 |
|---|---|---|---|---|
| Sentinel-2 (현재 20m로 사용) | **10m** (B4/B8) | 20m | 무료 | 지금 당장 2배 정밀 가능 |
| PlanetScope | 3m (4밴드 2014+, 8밴드 2020+) | 없음 | E&R 승인 시 무료 | 대학 이메일 필수 |
| CAS500-1 (국토위성) | MS 2m / PAN 0.5m | 없음 | 주문(SIIS/국토위성센터) | **2021 발사** → 안동2020 불가 |
| Airbus Pléiades Neo | MS **1.2m** → PAN융합 30cm | 없음 | 유료 | **2021 발사** → 안동2020 불가 |
| Maxar WorldView | ~1.2m급 | 일부 O | 유료 | 상품·권한 확인 필요 |

### 이전 오류 정정 (2026-09-06)
1. KOMPSAT-3A ≠ CAS500-1(국토위성)은 다른 위성. CAS500-1 = PAN 0.5m/MS 2m, 2021 발사.
2. Pléiades Neo도 2021 발사(안동2020 불가), NIR 있으나 SWIR 없음.
3. **30cm 출력 ≠ NIR 관측 해상도**. Neo MS native 1.2m를 PAN과 융합해 30cm 제품.

## 3. native vs pan-sharpened — 요구사항 구분 (핵심 설계 결정)
- **소각 탐지·심각도(정량 dNDVI)** = NIR *분광값* 의존 → **native MS 해상도가 진짜 유효 해상도**
  (Neo 1.2m, CAS500 2m). 팬샤프닝은 분광 왜곡(JRC 평가 보고서).
- **소각 경계(면적 산정)** = 공간 정보 → PAN 30~50cm 유효.
- **권고**: native MS NIR 1~2m(탐지) + PAN 30~50cm(경계 refinement) **하이브리드**.
  native 30cm 다분광은 사실상 없음 → "원래 sub-meter NIR" 고집 시 트랙 사망.
  native 1~2m도 20m 대비 10~20배 = 충분한 도약.

## 4. 대상 화재
- **포기**: 안동2020 (Neo·CAS500 발사 전).
- **타깃**: 울진2022 · 의성2025 · 산청2025 (전부 2021 이후 → Neo/CAS500/WV 커버 가능 + GT 보유).

## 5. 무료 해상도 사다리 (권고 실행 순서)
1. **S2 10m 재타일링** — 발급 0, 즉시. 20m 대비 경계 정밀도 측정. (dNDVI 10m, dNBR 20m)
2. **PlanetScope 3m** — E&R 프로그램(대학 이메일 필수) 승인 시 무료, 월 ~3,000km².
3. **유료 상용(Neo/Maxar)** — 위 둘로 부족할 때만. OneAtlas 아카이브 검색(무료)으로
   pre(화재-30d)/post(화재+6~28d) 저운량 쌍 실존 확인 → 소액 1건 파일럿 → 확장.

## 6. PlanetScope 발급 절차
- **API 키**: planet.com 계정 → My Settings → API Key (즉시 무료, env `PL_API_KEY`). 단 키만으론 검색만, 다운로드 권한 없음.
- **무료 영상**: E&R(Education & Research) 프로그램 승인 필요.
  - 자격: 대학 소속 학생/교수/연구원 + **대학 이메일(.ac.kr) 필수**. 비영리·정부직원 불가.
  - 혜택: PlanetScope 3m 4/8밴드 + RapidEye + 베이스맵, 월 ~3,000km².

## 7. 처리 파이프라인 (데이터만 오면 코드로 해결)
- 기존 변화탐지 모델은 **RGB+NIR 8채널** 학습 → SWIR 없는 3m/1~2m 4밴드와 밴드 호환 좋음.
- 신규 필요 모듈: **서브픽셀 co-registration**(고해상은 pre/post 미세 오정합 치명적, 20m엔 불필요했음).
- 그 외: 리타일링(512px), 반사율 스케일 정규화(오프셋 이중보정 버그 교훈), dNDVI/dNBR.
- ⚠️ 스토리지: 25cm는 20m 대비 면적당 픽셀 6,400배 → 화재당 수 GB.
