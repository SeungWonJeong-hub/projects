# NGII 근적외선(NIR) 고해상 정사영상 자료신청 — 문의 초안

목적: 산불 소각영역 산출 연구용으로 **근적외선(NIR) 포함 고해상(12~25cm) 정사영상 또는 원시영상**을
받을 수 있는지, 가능하다면 절차·형식·비용을 확정하기 위함.

배경(이미 확정된 사실, 다시 물을 필요 없음):
- 국토정보플랫폼 공개 API(WMTS/WMS/WCS) = **RGB 전용**으로 실측 확인됨.
- 화재이벤트 다운로드 번들 = Sentinel-2 10m CIR + 수치지도 벡터뿐(고해상 항공 NIR 없음).
- ngii.go.kr(sq=202)에 "종류별 원시영상(RGB, NIR) DB 구축" 명시 → NIR은 물리적으로 존재.

연락처: 국토지리정보원 031-210-2798 (전화) / 국토정보플랫폼 문의.

## 결정적 질문 5개 (이 답이 트랙 성패를 가름)

1. **NIR 밴드 납품 가능 여부**
   "국토정보플랫폼에서 배포되는 25cm(도시 12cm) 정사영상 TIFF에 근적외선(NIR) 밴드가 포함됩니까?
   포함 안 된다면, RGB+NIR 4밴드 또는 색적외선(CIR) 형태의 정사영상/원시영상을 별도 신청으로 납품받을 수 있습니까?"

2. **공간해상도**
   "납품 가능한 NIR 포함 영상의 실제 GSD는 몇 cm입니까? (12cm/25cm/기타)"

3. **신청 자격**
   "연구 목적(비영리·학술)으로 개인 또는 연구팀이 신청 가능합니까,
   아니면 공공기관·지자체 공문 제출이 필수입니까? 필수라면 협력 가능한 경로가 있습니까?"

4. **형식·좌표·비용·기간**
   "납품 형식(GeoTIFF 원시 반사율/DN 여부), 좌표계(EPSG:5179/5186),
   비용(무료/유료 단가), 처리 소요기간을 알려주십시오."

5. **대상 지역·시기 커버리지**
   "특정 산불 발생 지역·연도(예: 2020 안동, 2022 울진, 2025 의성/산청)에 대해
   화재 전후 시점의 NIR 정사영상이 존재합니까? 연 1회 촬영이면 화재를 시간적으로 감쌀 수 있습니까?"

## 문의 이메일/공문 본문 (복사용)

제목: 근적외선(NIR) 포함 고해상 정사영상 자료신청 가능 여부 문의 (산불 피해평가 연구)

안녕하십니까.
산불 소각영역 자동 산출 연구를 진행하고 있는 [소속/이름]입니다.

국토정보플랫폼의 공개 정사영상 및 API(WMTS 등)를 검토한 결과 RGB 3밴드만 제공됨을 확인하였고,
귀 기관 안내(항공사진 촬영, RGB·NIR 원시영상 DB 구축)에서 근적외선 영상이 별도 구축됨을 확인하였습니다.

소각지 판별은 근적외선(NIR)·단파적외선 대역에서 가장 명확하므로,
아래 사항의 가능 여부를 문의드립니다.

1. 배포 정사영상(12/25cm) TIFF에 NIR 밴드 포함 여부, 또는 RGB+NIR 4밴드/CIR 정사영상 별도 납품 가능 여부
2. 납품 가능 시 실제 GSD, 형식(GeoTIFF 원시 밴드값 여부), 좌표계, 비용, 소요기간
3. 연구 목적 개인/연구팀 신청 자격(공문 필수 여부)
4. 특정 산불 지역·연도(예: 2022 울진)의 화재 전후 NIR 영상 존재 여부

회신 주시면 후속 절차를 진행하겠습니다. 감사합니다.

## 셀프체크 (문의와 병행, 5분)

국토정보플랫폼 로그인 → 정사영상 1타일 대용량전송 S/W로 다운로드 → 밴드 수 확인:

    gdalinfo <정사영상>.tif | grep -c "^Band "

- 결과 4 이상 & 그 중 NIR 존재 → **문의 없이도 트랙 즉시 개시 가능** (API만 RGB였을 뿐 원본 TIFF는 4밴드).
- 결과 3 → 공식 API 판정과 동일(RGB), 위 문의 경로만 유효.
