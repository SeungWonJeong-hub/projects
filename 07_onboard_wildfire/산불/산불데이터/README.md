# 산불 데이터

산불 변화탐지 일반화 검증용 **실측 라벨 데이터** 모음.

## 목적
20m Sentinel-2 산불 변화탐지 모델의 **교차지역 일반화 검증**에 쓰는 실측 소실경계(ground-truth burn perimeter).
- 관련 조사: [../울진산불_변화탐지/GENERALIZATION.md](../울진산불_변화탐지/GENERALIZATION.md)
- 검증한 생물군계(2026-08-15): 지중해(캘리포니아·유럽)·한대림(알래스카)·유칼립투스(호주) — 모델은 어디서도 붕괴 안 함, 단 dNBR 대비 우위는 도메인 거리에 반비례.
- **미검증(데이터 벽): 열대·사바나, 동아시아·한국** — 20m급 실측라벨이 이 지역엔 사실상 없음.

## 여기에 넣을 것 (한국 검증용)
- **울진 2022 등 한국 산불 피해구역 폴리곤** (shapefile `.shp/.dbf/.shx/.prj` 세트 또는 `.geojson`)
- 취득처: 국가공간정보포털(nsdi.go.kr) / 산림공간정보서비스(fgis.forest.go.kr) / data.go.kr / 지자체·산림청 보고서
- 있으면 래스터화 → 울진 S2와 정합 → 미국·유럽 학습 모델의 한국 실측 F1(dNBR 대비 마진) 측정.
