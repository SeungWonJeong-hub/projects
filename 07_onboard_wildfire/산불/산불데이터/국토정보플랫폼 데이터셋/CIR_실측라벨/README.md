# 국토정보플랫폼 산불 CIR 실측라벨 드롭 폴더

CIR-GT 봄 파인튜닝용 화재별 실측라벨 원본을 여기에 넣는다.
안동(200424_안동풍천면) 파이프라인과 동일 구조 → `src/ngii_cir_gt.py` 로 GT 자동생성.

## 화재 1건 = 서브폴더 1개 (이름: `YYMMDD_지역명`)
예) `220305_울진`, `250322_의성`

각 폴더에 넣을 것:
- **Sentinel CIR pre/post 2장** (필수) — `CompResult_SEN_MMDD_CIR_s.tif` 형식.
  화재 직전 + 직후 타이트 브래킷(dNDVI 자동라벨 핵심). ※KOMPSAT 단일일자는 불가(pre/post 없으면 무의미)
- **농경지레이어** (필수) — 오탐 마스킹 (검증됨, precision +0.03)
- **도로레이어** (필수) — CIR 지오레퍼런싱 앵커
- **호수,저수지 + 실폭하천** (권장) — 물 오탐 마스킹
- **해안선** (동해안 화재만) — 바다 오탐 마스킹
