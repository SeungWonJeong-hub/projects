# 미학습 화재 데모 — 안동 길안면 2025 (before/after, 20m·10m)

웹앱(변화탐지)에서 **미학습(학습에 안 쓴) 화재**를 20m·10m 두 해상도로 돌려보기 위한
before/after 원본 씬. 안동 2025는 NIFoS 0.3m 독립 자가 있는 화재로, 모델 학습에는
들어가지 않았다(독립 검증용 홀드아웃).

## 화재
- 안동 길안면, 2025년 3~4월 산불 · 소각 약 2,000 ha
- pre(before) **2025-03-22** (☁0.0%) · post(after) **2025-04-11** (☁0.1%)
- 출처: Sentinel-2 L2A `S2C_52SDF_*` (earth-search STAC, 무인증) · AOI 크롭 EPSG:32652

## 파일
| 파일 | 용도 |
|---|---|
| `before_20m.tif` / `after_20m.tif` | **20m 모델용** 업로드 (밴드 `[B02,B03,B04,B8A,B11,B12]`) |
| `before_10m.tif` / `after_10m.tif` | **10m 모델용** 업로드 (밴드 `[B02,B03,B04,B08,B11,B12]`) |
| `before_rgb.png` / `after_rgb.png` | 눈으로 보는 미리보기(트루컬러). before=초록 숲, after=갈색 소각흔 |
| `gt_20m.tif` | 정답 마스크(소각=1, 20m 격자) — 정확도 표시용, 선택 |

> 20m 모델은 NIR=**B8A**(865nm, 네이티브 20m), 10m 모델은 NIR=**B08**(842nm, 네이티브 10m)로
> 학습됐다. 그래서 해상도별로 NIR 슬롯이 다른 파일을 따로 둔다. 밴드 순서는
> `io_bands.BAND_ORDER` 규약(4번 슬롯=그 파일이 담은 NIR).

## 웹앱에서 쓰는 법
1. 입력 방식 = **GeoTIFF 업로드**
2. 사이드바 **해상도(GSD)** 에서 20m 또는 10m 선택
3. 20m 이면 `*_20m.tif`, 10m 이면 `*_10m.tif` 를 Before/After 에 각각 올린다
4. (선택) 정답 마스크에 `gt_20m.tif` 를 올리면 Precision/Recall 이 뜬다

## 검증(이 데모로 실제 돌린 값)
- 20m: 소각 49,616 px(≈1,985 ha) · GT 대비 **P 0.833 · R 0.965 · F1 0.895**
- 10m: 소각 201,629 px(≈2,016 ha) — 면적 일치(격자가 달라 20m GT와 직접 F1은 생략)
