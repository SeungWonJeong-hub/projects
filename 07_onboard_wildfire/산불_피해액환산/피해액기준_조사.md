# 산불 피해액(원화) 산정 기준 조사

작성일 2026-09-10. 목적: Sentinel-2 변화탐지 파이프라인이 산출하는 소각면적(ha)을
"국가 기준 피해액 + (민간 기준 피해액)"으로 환산하는 모듈의 근거 정리.

정직성 표기 규칙:
- [원문확인] = 해당 URL 원문/본문에서 직접 확인한 수치
- [스니펫] = 검색 스니펫·2차 요약에서만 확인 (원문 표/PDF 미확인)
- [역산] = 공개 총액/면적을 나눠 우리가 계산한 파생값 (공식 고시치 아님)
- [미확인/추정] = 근거 약함, 보수적 기본값으로만 사용

즉 우리 파이프라인의 area_ha에 대해:
- **국가(사회적 총손실)** ≈ 임목직접(≈990만/ha) + 공익기능(≈4,110만/ha) + 복구·진화(≈500만/ha) ≈ **5,000만~5,600만원/ha**
- **민간(산주 사적 실손, 정정)** ≈ 임목자산(≈840만/ha) + 재조림비(≈700만/ha) + 지가하락(소액/0) ≈ **1,500만원/ha 내외**.
  기존 "임목값만(≈840만)"에서 **재조림비를 더해 상향**했으나, 공익기능을 포함하는 국가 기준보단 여전히 작다. (2-2b 절)

## 1. 국가(공식) 기준

### 1-1. 산불 피해액의 4대 구성 [원문확인 - e-나라지표 idx_cd=1309]

산림청 산불 피해액 산정은 2011년부터 방식이 변경되었고, 다음 4개로 구성:

1. **직접피해액** — 입목(임목) 피해 등
2. **복구비** — 조림 및 응급복구
3. **진화비용** — 인력 및 헬기 진화비용
4. **공익비용** — 공익적 손실(산림 공익기능 상실분)

출처: https://www.index.go.kr/unity/potal/main/EachDtlPageDetail.do?idx_cd=1309 (e-나라지표 "산불발생현황", 관련용어)
상세 연도별 수치는 산림청 『산불통계연보』(매년 익년 2월) PDF에 있음 — 본 조사에서 PDF 원문 표는 미열람.

### 1-2. 임목(직접) 피해 산정 방법 [스니펫 - 산림청 요약]

산불피해지의 임목축적을 **임상도(임상별: 침엽수·활엽수·혼효림, 영급별)** 로 산출 →
**재적표 및 임목자산평가기준표**로 경급별·등급별 환산 →
**현지 임목매각 실적 평균 임목가** 적용.

즉 공식은 개념적으로:
```
임목직접피해(원) = 피해면적(ha) × 단위면적당재적(m³/ha) × 평균임목가(원/m³) × 피해율
```

- 단위면적당재적(전국 평균): **165.2 m³/ha** (2020년 말, 제7차 국가산림자원조사)
  [원문확인/스니펫 - 산림기본통계]. 참고: OECD 평균 131 m³/ha.
  출처: https://www.forest.go.kr/kfsweb/kfi/kfs/cms/cmsView.do?mn=NKFS_04_05_01&cmsId=FC_000065
- 평균 임목가(원/m³): **[미확인/추정]**. 국산 원목 시장가격은 한국목재신문/산림청
  "국산재 원목 시장가격 동향"에 있으나 표가 이미지라 정확 단가 원문 확인 실패(403 아님, 차트 이미지).
  실무 감정에서 입목가는 원목시장가에서 벌채·반출비를 공제(시장가역산법)하므로 원목가보다 낮음.
  보수적 기본값 **6만원/m³** 사용(소경목·혼효림 포함 평균 가정). 갱신 필요.
  출처(원목가격): https://www.woodkorea.co.kr/news/articleView.html?idxno=78680

### 1-4. 법적 근거 (개념)

산림보호법·산림자원의 조성 및 관리에 관한 법률 및 산림청 예규(산불피해조사 지침)에 따라
피해조사·피해액 산정. 본 조사에서 예규 조문 원문(고시번호·별표 단가)까지는 미확보. [미확인]

## 2. 민간(보험·감정평가) 기준

### 2-1. 입목 감정평가 방법 [원문확인 - 감정평가 실무자료]

민간은 "공익기능"을 계상하지 않고 **임목 자체의 자산가치**만 평가. 임령(성장단계)별로:

| 임령 단계 | 평가법 | 개념 |
|---|---|---|
| 유령림(소경목) | **원가법(육성비용가법)** | 그때까지 투하된 육성비 합산 |
| 중령림 | **글라저법(Glaser)** | 원가·수익 절충 |
| 장령림 | **기망가법(Faustmann 계열)** | 벌채 시 기대수익 현재가 할인 |
| 성숙림 | **시장가역산법** | 원목시장가 − 벌채·반출비 = 입목가 |
| 전반 | **거래사례비교법** | 유사 입목 거래사례 보정 |

출처: https://pagarlic.com/산림의-감정평가-... (감정평가 실무 정리)

### 2-2. 산림/임야 화재 보험 보상 [미확인]

- 임야화재·산림보험은 임목 시장가치(원목 환산가)와 지장물 위주로 보상하며,
  공익기능·경관·탄소 등 외부효과는 보상 대상 아님.
- 임업재해보험(NH농협손해보험 위탁, 산림청 정책보험): 본 조사에서 대상품목은 임산물
  (떫은감·밤·대추·표고·복분자·오미자)과 임업인 안전으로 확인됨. **일반 임목(입목) 자체를
  대상으로 한 산불 보상은 공개자료상 확인 못함** — 즉 대부분의 산주는 임목 손실을
  보험으로 회수하지 못하고, 국가 재난지원금(정액, 소액)+세제감면에 의존. [미확인/부분확인]
  출처: forest.go.kr 임업재해보험 리플릿, nhfire.co.kr

### 2-2b. [정정] 산주의 사적 실손 재구성 — 조림비 + 지가하락 추가

기존 "민간=임목값만, 국가의 15~30%"는 **산주 실손을 과소평가**했음. 산주가 실제로
잃거나 지출하는 손실에는 최소 3요소가 있다:

**(A) 임목 자산가치** — 위 2-1 감정평가. (기존 반영됨)

**(B) 재조림비 실손** [부분확인/추정]
산불로 죽은 임분을 다시 세우는 실제 비용(식재+5년 사후관리: 풀베기·어린나무가꾸기).
- 조림 국고보조는 **사업비의 90%(국고 70%+지방비 20%), 산주 자부담 10%** [원문확인]
  출처: iforest.nfcf.or.kr(산림조합), 금산군 2026 보조조림 공고문(자부담 10% 명시)
- **울진·삼척 산림생태복원: 보호구역 4,789ha에 325억원(2023~2027)** → 약 **679만원/ha**
  (단, 조림 49% + 자연복원 51% 혼합이라 순수 인공조림보다 낮음). [원문확인/역산]
  출처: south.forest.go.kr 보도자료, businesskorea 275915
- 순수 인공조림+5년 사후관리 총비용은 통상 **ha당 500만~1,000만원**으로 알려짐(식재
  3,000본/ha 내외 + 다년 풀베기). 정확 표준단가는 산림청 표준품셈/토목단가 CSV·이미지표라
  원문 수치 추출 실패. **보수적 기본값 700만원/ha** 사용. [미확인/추정, TODO]
- 산주 관점: 국고보조가 있으면 **실제 자부담은 10%**지만, "손실"로서의 재조림비 전액은
  700만/ha다. 모듈은 전액(사회적 실손)과 자부담분(현금지출)을 구분 가능하게 둠.

**(C) 임야(토지) 지가 하락분** [미확인 — 핵심 불확실]
- **한국 감정평가 원칙상 임지(토지)와 임목은 분리평가**한다. 임야 공시지가/감정가는
  용도지역·입지·도로조건 기준(공시지가기준법)이며, 임목은 정착물로 별도. 따라서
  **임목이 타도 토지 자체의 공시지가는 직접적으로는 거의 변하지 않는다**는 것이 실무 원칙.
  출처: first-a.kr(임야 감정평가), pagarlic.com(임지·임목 분리평가)
- 그러나 실거래·시장 심리에서는 벌거숭이가 된 임야의 매매가 하락·매물 증가가 발생할 수
  있음(경관·이용가치·송이 등 임산물 생산기반 훼손). 영덕 송이산지 붕괴 사례는 임산물
  생산기반 손실을 지적. 출처: kfnews 5976
- **한국 산불 후 임야 지가 하락률의 공개 정량자료(원/㎡ 또는 %)는 이번 조사에서 확보 실패.**
  분리평가 원칙상 하락은 있어도 임목값·조림비보다 작을 가능성. **보수적 기본값: 지가의
  5% 하락, 임야 단가 미상이면 0으로 처리(과대추정 방지).** [미확인/추정, TODO]

### 2-3. 국가 vs 민간 개념 재정리 (핵심)

- **국가(공식) = 사회적 총손실.** 임목직접 + 복구비 + 진화비 + **공익기능 손실(4,110만/ha)**.
  공익기능이 압도적 비중(울진 역산에서 약 73%).
- **민간(산주 사적 실손) = 임목 자산가치 + 재조림비 실손 + 지가하락분.** 공익기능·진화비는
  산주가 못 받으므로 제외. 대신 국가 계산에서 과소평가됐던 **재조림 전액과 지가하락을 포함**.

| 구성요소 | 국가(공식) | 민간(산주 실손) |
|---|---|---|
| 임목 직접피해 | O (평가기준표·평균임목가) | O (시장가역산·감정, 보수계수) |
| 재조림비(실손) | O(복구비에 포함) | **O (신규 반영, 전액 or 자부담)** |
| 진화비 | O | X |
| 공익기능 손실 | O (4,110만/ha) | X |
| 임야 지가하락 | X(토지는 국가피해 대상 아님) | **O (신규 반영, 소액·미확인)** |

→ 재설계 후 민간 기준은 임목값만일 때보다 **재조림비+지가하락만큼 커진다**. 다만
공익기능(4,110만/ha)을 포함하는 국가 기준이 여전히 훨씬 크다(민간 < 국가 유지).
